# RepoWatch 0.1.0b1 — first public beta

RepoWatch is an MIT-licensed, self-hosted dashboard for the public repositories of one
GitHub account. It retains observed traffic history beyond GitHub's rolling window and
puts visits, star balances, release downloads and community activity in one place.

## Included

- Docker Compose installation with persistent SQLite storage, a non-root image, a protected
  web service and automatic collection every six hours.
- Built-in Basic authentication requiring both credentials, or explicit delegation to an
  existing authentication proxy. TeleLogin is optional.
- Overview charts, repository sparklines, search, sorting, filters and light/dark themes.
- Separate cumulative release totals and observed period download increases, complete UTC
  windows, traffic coverage and gaps for missing daily observations.
- Verified compressed database backups, retention and documented restore procedures.
- Documentation screenshots generated from synthetic data; no maintainer analytics are used.
- CI tests on Python 3.11–3.13 and a fresh Docker install using a fake GitHub API, covering
  login, collection, persistence and backup/restore. Beta publication waits for these checks.

## Install

Download the source archive for this tag, or clone and check out the release:

```bash
git clone https://github.com/downlevel/repowatch.git
cd repowatch
git checkout v0.1.0b1
cp .env.example .env
```

Set `GITHUB_OWNER`, `GITHUB_TOKEN`, `DASHBOARD_USER` and `DASHBOARD_PASSWORD`, then run
`docker compose up -d --build`. Open http://127.0.0.1:8765. The image is built locally;
no prebuilt registry image or PyPI release is published as part of this beta.

[Installation and operations](https://github.com/downlevel/repowatch/blob/v0.1.0b1/docs/self-hosting.md)
· [Manual Python installation](https://github.com/downlevel/repowatch/blob/v0.1.0b1/docs/manual-installation.md)

## Upgrade from earlier checkouts

Back up your SQLite database before upgrading. If an authentication proxy protects your
existing instance and you previously omitted dashboard credentials, explicitly set
`DASHBOARD_AUTH=external` before restarting. Otherwise, configure both dashboard credentials;
Basic mode now refuses to start without them. Rebuild/recreate Docker services after changing
the code or environment. Preserve your data volume and keep a backup outside it.

## Beta limitations

- Public repositories only, one account and one dashboard credential pair per installation.
- Traffic requires suitable GitHub access. Old traffic cannot be reconstructed; counter
  trends need multiple observations and incomplete coverage limits comparisons.
- Daily unique visitors are summed observations, not distinct people over the entire period.
- Downloads are asset counter observations, including auxiliary files; changing the asset
  inventory can affect period differences. CI checkout estimates do not count human clones.
- Referrer/path snapshots cover GitHub's latest 14 days and do not follow the period selector.
- Chart.js currently loads from jsDelivr, requiring browser access to that CDN.
- No hosted multi-user service, launch annotations or public interactive demo yet.
- Automated Docker backups require a schedule configured by the operator.

Please report reproducible problems in
[GitHub issues](https://github.com/downlevel/repowatch/issues), including the version,
installation method, selected period and redacted logs. Do not include credentials,
`.env` files or private databases.
